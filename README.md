# Lot7 — ロト7 当せん番号 予想・検証ツール

過去の当せん番号から統計量を取り出し、その傾向に沿った買い目を組み立てる Python ツールです。
同時に、**その買い目に予測力があるのかを過去データで検証する機能**を備えています。

---

## ⚠️ 最初に読んでください

ロト7 の抽せんは**毎回独立した試行**です。前回までにどの数字が出たかは、次回にどの数字が
出るかに一切影響しません。したがって——

* 過去の当せん番号から次回の当せん番号を**当てることはできません**。
* 「よく出る数字」「そろそろ出る数字」を選んでも、1 口の当せん確率は
  **1等 1/10,295,472 のまま**変わりません。
* 1 口 300 円あたりの期待値は約 **136 円（回収率 45%）** です。どの選び方をしても
  期待値は購入額を下回ります。

このツールが実際にやっているのは次の 3 つです。

1. 過去データの統計的な性質を**可視化**する（出現回数・出現間隔・合計値・奇偶比 など）
2. その傾向に沿って、偏りのない**買い目を機械的に組み立てる**（毎回悩まなくて済む）
3. その買い目が**本当にランダムより優れているかを検証する**（`backtest` / `compare`）

3 番目が本ツールの一番大事な機能です。付属のシミュレーションデータ（＝完全な乱数）で
検証すると、どのモデルも理論値 1.3243 個の近傍に落ち着き、ランダムと区別がつきません。
実データで試しても同じ結果になるはずです。それが正しい姿です。

## データの準備

同梱の `data/sample_simulated.csv` は**一様乱数で生成した架空の履歴 600 回分**です。
実際の当せん番号ではありません。動作確認とランダムの基準線としてのみ使ってください。

実データを使うには、次のいずれかで差し替えます。

```bash
# 1) 公式サイトから取得を試みる（ページ構造やネットワーク制限で失敗することがあります）
python -m loto7 --data data/loto7.csv fetch

# 2) 手元の CSV を取り込む（確実な方法）
python -m loto7 --data data/loto7.csv import path/to/downloaded.csv
```

CSV は次の形式です（`#` で始まる行はコメント、日付は空でも可）。

```csv
round,date,n1,n2,n3,n4,n5,n6,n7,b1,b2
1,2013-04-05,7,15,22,23,27,32,37,11,28
2,2013-04-12,1,2,4,8,20,28,29,11,30
```

以降の例では `--data data/loto7.csv` を付けてください（省略時は同梱のシミュレーションデータ）。

## 使い方

### 買い目を生成する

```bash
python -m loto7 predict -n 5 --model ensemble --seed 42
```

```
次回（第601回）の買い目候補:
  候補1:  8 11 17 26 34 36 37   [合計 169 / 奇数 3 / スコア +0.860]
  候補2:  3  5 18 26 29 30 36   [合計 147 / 奇数 3 / スコア +0.595]
  候補3:  3  8 11 15 16 29 36   [合計 118 / 奇数 4 / スコア +0.658]
  候補4:  8 17 18 20 30 35 36   [合計 164 / 奇数 2 / スコア +0.613]
  候補5:  3  7  8 11 18 26 36   [合計 109 / 奇数 3 / スコア +0.744]
```

主なオプション:

| オプション | 説明 |
| --- | --- |
| `-n, --count` | 生成する口数（既定 5） |
| `--model` | `hot` / `cold` / `overdue` / `markov` / `uniform` / `ensemble`（既定） |
| `--temperature` | 大きいほどランダムに近づく（既定 1.0） |
| `--diversity` | 口同士の数字の重なりを減らす強さ（既定 0.15、0 でスコア順） |
| `--include` / `--exclude` | 必ず含める / 除外する数字（例 `--include "7 13"`） |
| `--no-constraints` | 出目の形（合計・奇偶・連番）の制約を外す |
| `--seed` | 乱数シード。同じ値なら同じ買い目が再現されます |

### 統計を見る

```bash
python -m loto7 stats --sort score
```

出現回数・期待値との差・直近の不在回数・平均出現間隔に加え、
**「すべての数字が等確率」という帰無仮説のカイ二乗検定**を表示します。
実データでもたいてい p 値は 0.05 を上回り、「よく出る数字」は統計的に確認できません。

### 検証する（重要）

```bash
python -m loto7 backtest --model ensemble --tickets 5 --warmup 100
```

各回について「その時点までの履歴だけ」でモデルを組み、実際の当せん番号と突き合わせる
ウォークフォワード検証です（先読みは `tests/test_backtest.py` で防止を確認しています）。

```
平均一致数       : 1.3296 個
ランダムの期待値 : 1.3243 個
z 値             : +0.28  （|z| < 2 なら偶然の範囲内 = ランダムと区別できない）
```

全モデルを一括比較:

```bash
python -m loto7 compare --tickets 5 --warmup 100
```

```
モデル        平均一致数     z 値   4個以上    回収率
-----------------------------------------------------
cold              1.3512    +1.42        37    214.6%
hot               1.3056    -0.99        34     17.8%
markov            1.3084    -0.84        50     23.6%
overdue           1.3472    +1.21        35     21.6%
uniform           1.3008    -1.24        32     20.2%
ensemble          1.3296    +0.28        35     19.6%
-----------------------------------------------------
理論値            1.3243    +0.00
```

この表の読み方こそが本ツールの主眼です。`cold` の回収率 214.6% は
**3等が 1 回当たっただけ**で生まれた数字で、平均一致数を見れば z 値は +1.42、
つまり偶然の範囲内です。回収率のような裾の重い指標は少数の当たりで簡単に跳ね上がり、
「このモデルは効く」という錯覚を生みます。判断は平均一致数と z 値で行ってください。

### 確率と期待値

```bash
python -m loto7 odds
```

### 買い目を照合する

```bash
python -m loto7 check "4 6 12 14 15 27 33" --round 600
```

## モデルの中身

| モデル | 考え方 |
| --- | --- |
| `uniform` | すべての数字を等価に扱う。**理論的に正しい基準線** |
| `hot` | よく出ている数字を高評価（新しい抽せんほど重み大、半減期 60 回） |
| `cold` | 出現の少ない数字を高評価（`hot` の符号反転） |
| `overdue` | `直近の不在回数 ÷ 平均出現間隔` が大きい数字を高評価 |
| `markov` | 直近の抽せん数字との共起頻度が高い数字を高評価 |
| `ensemble` | `hot` 0.35 + `overdue` 0.35 + `markov` 0.30 の加重合成（既定） |

`hot` と `cold` は正反対の戦略ですが、検証するとどちらも同じ結果になります。
これは「どちらが正しいか」ではなく「どちらにも予測力がない」ことを意味します。

スコアは z 標準化してソフトマックスで重みに変換し、Gumbel-top-k による重み付き
非復元抽出で買い目を作ります。そのうえで過去の出目の形（合計値・奇数の個数・
前半/後半の比・連番ペア数の中央 90% レンジ）に合う候補だけを残し、
スコアと口同士の重なりの少なさを両立させて貪欲に選びます。

  rules.py      ゲームルールと当せん等級の判定・理論確率
